# NawyOrders PWA

The Progressive Web App (PWA) frontend for the NawyOrders platform.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Getting Started

Project setup and installation instructions will be added during development.

## Branching Strategy
- `master`: Stable code.
- `development`: Development and integration.
- `feature/*`: Individual task branches.

## Contributing
Create a separate branch for each task and open a Pull Request into `development`.
